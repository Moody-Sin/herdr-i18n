# Herdr 简体中文本地化术语表 (Glossary)

此文档为 Herdr 简体中文本地化的标准术语对照表。所有界面文案（`src/i18n/zh-CN.json`）、CLI 帮助文本、报错信息以及中文文档均需严格遵循本规范，以保持术语一致性与开发者直觉体验。

---

## 1. 界面与容器布局 (Layout & Hierarchy)

| 英文术语 | 标准译名 | 规范与说明 | 常见反例 / 禁忌 |
| :--- | :--- | :--- | :--- |
| **Workspace** | **工作区** | Herdr 顶层工作区实体，如“新建工作区”、“切换工作区” | 禁译为“空间”、“工作空间” |
| **Pane** | **窗格** | 终端分屏的最小视图单元，如“重命名窗格”、“分割窗格” | 禁译为“面板”、“窗口” |
| **Tab** | **标签页** | 工作区内的分页容器，如“新建标签页”、“关闭标签页” | 禁译为“选项卡”、“标签” |
| **Split** | **分割** | 分屏动作或状态，如“垂直分割”、“向下分割” | 避免译为“拆分”、“分屏” |
| **Zoom** | **放大 / 缩放** | 动词操作使用“放大”（如“放大窗格”），名词属性使用“缩放” | 避免界面按钮混用 |
| **Resize** | **调整大小** | 如“调整大小模式”、“调整窗格大小” | 避免单字“调整”产生歧义 |
| **Swap** | **交换** | 如“与当前焦点窗格交换” | 避免译为“对调”、“互换” |
| **Cycle** | **切换** | 窗格间轮换跳转，如“切换窗格”、“切换到下一个窗格” | 避免译为“循环” |
| **Focus** | **聚焦 / 焦点** | 动作作“聚焦”（如“聚焦相邻窗格”），名词作“焦点”（如“移动焦点”） | 避免动作混用为“专注于” |
| **Sidebar** | **侧边栏** | 如“切换侧边栏”、“设置侧边栏显示的机器标签” | 禁译为“边栏” |

## 2. Git 与版本控制 (Git & Version Control)

| 英文术语 | 标准译名 | 规范与说明 | 常见反例 / 禁忌 |
| :--- | :--- | :--- | :--- |
| **Worktree** | **工作树** | 遵循老大要求全量汉化为“工作树”（如“新建工作树”、“打开工作树”） | 禁留英保留“worktree” |
| **Checkout** | **检出目录 / 检出** | 名词作“检出目录”（如“删除工作树检出目录”），动词作“检出” | 禁译为“签出” |
| **Branch** | **分支** | Git 分支，如“新建分支”、“分支名称” | - |
| **Dirty / Untracked**| **未提交 / 未跟踪** | Git 文件状态，如“未提交或未跟踪的文件将被永久删除” | 禁生硬直译为“脏文件” |

## 3. 会话与网络架构 (Runtime, Network & Federation)

| 英文术语 | 标准译名 | 规范与说明 | 常见反例 / 禁忌 |
| :--- | :--- | :--- | :--- |
| **Session** | **会话** | 如“持久会话”、“会话导航器” | - |
| **Machine** | **机器** | 指已保存配置的 SSH 远端主机，如“已保存的 SSH 机器” | 避免译为“主机”、“服务器”造成混淆 |
| **Endpoint** | **端点 / 连接** | 通信连接或服务端点（如“SSH 端点联合”、“连接不可用”） | **严禁译为“终端”**（避免与 Terminal 混淆） |
| **Terminal** | **终端** | 指终端仿真器、PTY、TTY，如“终端工作区管理器”、“通过终端” | - |
| **Server / Client** | **服务器 / 客户端** | 如“远程服务器”、“已打开的 Herdr 客户端” | - |
| **Attach** | **连接** | 将前端挂载到后端会话/终端，如“连接到会话”、“连接 TUI” | 避免译为“附加” |
| **Detach** | **分离** | 保持后端运行、断开前端显示，如“分离” | 避免译为“脱离”、“断开连接” |
| **Reattach / Reconnect** | **重新连接** | 如“重新启动 Herdr 以重新连接” | 避免简写为“重连” |
| **Handoff** | **实时交接** | 升级或切换时无缝移交进程，如“实时交接” | 禁译为“握手”、“换手” |
| **Federation** | **联合** | 多端点互联，如“已保存的 SSH 端点联合” | 避免译为“联邦” |

## 4. 智能体与生命周期 (Agents & Lifecycle States)

| 英文术语 | 标准译名 | 规范与说明 | 常见反例 / 禁忌 |
| :--- | :--- | :--- | :--- |
| **Agent** | **智能体** | AI 辅助编程主体，统一使用“智能体” | **严禁译为“代理”** |
| **Prompt** | **提示词 / 提示符** | 智能体输入作“提示词”；Shell 命令提示符作“提示符” | 区分语境，禁混用 |
| **Working** | **工作中** | 智能体状态：活跃处理中 | 避免译为“运行中” |
| **Idle** | **空闲** | 智能体状态：等待输入/命令 | - |
| **Blocked** | **已阻塞** | 智能体状态：等待外部确认或受阻 | 避免译为“卡住” |
| **Done** | **已完成** | 智能体状态：任务结束 | 避免译为“做完了” |
| **Attention** | **需要关注** | 状态标签，统一为“需要关注” | 避免译为“需要注意” |
| **Online** | **在线** | 连接状态 | - |
| **Connecting** | **连接中** | 连接状态 | - |
| **Reconnecting** | **重新连接中** | 重连状态 | - |
| **Disabled** | **已禁用** | 状态词 | 避免译为“无效” |

## 5. 交互与配置系统 (Interaction, UI & Config)

| 英文术语 | 标准译名 | 规范与说明 | 常见反例 / 禁忌 |
| :--- | :--- | :--- | :--- |
| **Keybind / Shortcut** | **快捷键** | 统一为“快捷键” | 避免混用“按键绑定” |
| **Prefix mode** | **前缀模式** | tmux 风格前缀键触发的状态 | - |
| **Scrollback** | **回滚内容 / 回滚** | 指终端历史输出，如“编辑终端回滚内容” | 避免直译为“向后滚动” |
| **Copy mode** | **复制模式** | 终端查看和复制历史输出的模式 | - |
| **Toast / Popup / Notice** | **通知 / 通知弹窗** | 如“通知弹窗”、“显示通知” | - |
| **Indicator** | **指示符** | 如“智能体状态指示符” | 避免译为“指示器” |
| **Plugin** | **插件** | 如“工作流插件”、“列出已安装的插件” | - |
| **Integration** | **集成** | 内置智能体环境集成，如“智能体集成” | - |
| **Manifest** | **检测清单 / 清单** | 智能体规则配置文件，如“智能体检测清单” | - |
| **Channel** | **更新通道** | 如“更新通道” | 避免译为“频道”、“渠道” |
| **Stable / Preview** | **stable / preview** | 通道名称保留小写英文，如“stable 或 preview 更新通道” | - |
| **Outdated** | **已过时** | 版本比较低于预期版本时使用“已过时” | **禁译为“已过期”**（避免与 Expired 混淆） |
